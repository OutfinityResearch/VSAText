Create Story Specification

The Create Story Specification page is the full-screen planning workspace for story setup before generation. It centralizes story core, cast, world setup, narrative structure, strategy, and quick templates in one place.

When to Use This Page

Use this page at the beginning of a project, or whenever you need a full regenerate with improved constraints and higher specification clarity.

What This Page Does

  • Collects high-level story constraints (genre, tone, complexity, length, cast size, world rules)
  • Captures character archetypes and trait sets
  • Defines location and artifact context
  • Sets narrative intent through structured dropdowns
  • Selects the generation strategy (Random, LLM, Advanced, Expert/Guided)
  • Applies quick templates for rapid initialization

Page Sections

Section Purpose Main Inputs
Store Core Define base narrative constraints Genre, tone, complexity, story length, number of characters, world rules, theme, wisdom
Characters Shape cast behavior and dynamics Protagonist, antagonist, secondary characters, relationships
The World and Locations Constrain setting and important objects Geography, time period, object types, significance
Narrative Structure Set structural direction Protagonist's Arc, Subplots, Conflict & Resolution
Generation Strategy Choose generation engine behavior Random, With LLM, Advanced, Expert / Guided
Quick Templates Apply one-click presets Classic Hero Quest, Murder Mystery, Romance Drama, Space Adventure, Horror Survival, Minimal

How to Use (Step by Step)

  1. Open Create Specs from the left sidebar.
  2. Fill Store Core first. This establishes global constraints used by all strategies.
  3. Define Characters with archetypes and traits. Add secondary characters only when needed.
  4. Set The World and Locations so scenes and objects have clear context.
  5. Pick Narrative Structure dropdowns to lock structural intent.
  6. Choose a Generation Strategy based on speed vs quality needs.
  7. Optionally apply a Quick Template if you need a starting scaffold.
  8. Click Generate to produce or regenerate the specification.

Strategy Selection Guide

Strategy Best Use Case Tradeoff
Random Fast ideation and rapid iteration Lower semantic depth
With LLM Richer semantics and creative variation Depends on model/API availability
Advanced Higher structural coherence and optimization Higher compute time
Expert / Guided Manual control with wizard flow More user input required

Example Input Bundle

Store Core
- Genre: Fantasy
- Tone: Dark
- Complexity: Moderate
- Story Length: Medium (8-12 scenes)
- Number of Characters: Medium (4-6)
- World Rules: Few
- Theme: "Duty versus personal freedom"
- Wisdom: "Power without restraint destroys trust"

Characters
- Protagonist: Seeker (curious, resilient, strategic)
- Antagonist: Ruler (calculating, manipulative, patient)
- Secondary: Mentor + Rival
- Relationships: alliance, rivalry

World and Locations
- Geography: mountain, city
- Time Period: medieval
- Objects: key, document
- Significance: central

Narrative Structure
- Protagonist's Arc: Hero's Journey
- Subplots: Betrayal
- Conflict & Resolution: Rising Tension

CNL and NL Impact

  • More complete inputs generally increase CNL specificity and reduce ambiguity.
  • Clear cast/world constraints improve character consistency and setting coherence.
  • Narrative dropdowns improve structural intent passed to generation and refinement.
  • Strategy choice affects speed, determinism, and output richness.

Best Practices

  1. Fill Store Core before touching templates or strategy.
  2. Keep trait selections focused; avoid selecting too many contradictory traits.
  3. Use secondary characters only when they serve a clear subplot purpose.
  4. Prefer one strong structural arc choice over mixed intent.
  5. If output quality drops, re-open this page and tighten constraints before regenerate.

New Project

The New Project wizard is the entry point for every new story. It captures the minimum project intent, creates the project container, and then sends the user directly into Book Settings.

Workflow Position

Use the wizard first. After clicking Create Project, the application opens Book Settings, starting with Story Core.

What This Page Does

  • Creates a new project with title, format, length, and seed ideas
  • Sets the initial context for Book Settings, Blueprint, and generation
  • Provides the minimum information needed before deeper planning
  • Starts the recommended flow without forcing full specification upfront

Main Inputs

Field Purpose
Title Names the book project and appears across the studio header
Format Defines the broad writing mode such as novel, short story, or screenplay
Length Sets an initial target scope for planning and generation
Seed Ideas Provides 2-3 core concepts that later become story structure and themes

How to Use

  1. Open the wizard from New in the application header.
  2. Enter a clear title and choose the broad project format.
  3. Select an initial length target.
  4. Write 2-3 seed ideas with strong narrative potential.
  5. Click Create Project.
  6. Continue in Story Core to shape the story foundation.

Best Practices

  1. Keep seed ideas short and concrete.
  2. Do not overload the wizard with full worldbuilding details.
  3. Use the wizard to establish intent, not to finalize structure.
  4. Move to Book Settings immediately after project creation.

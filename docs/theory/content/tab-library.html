Library

Library is the reusable resource area of the application. It stores templates and narrative assets that can be previewed, selected, and applied into the current project instead of being rebuilt from scratch each time.

Workflow Position

Library supports the main writing flow, but it is not a mandatory linear step. Authors typically create a project first, then apply reusable material from Library while working through Book Settings, Blueprint, Story Map, or Manuscript.

What Library Contains

  • Narrative Arc Templates - reusable arc models and structural patterns
  • Character Templates - reusable character seeds, archetypes, and trait bundles
  • Locations - reusable settings and place definitions
  • Objects & Artifacts - reusable story objects and symbolic items
  • Scenes & Plot Points - reusable structural or dramatic building blocks
  • Theme, Wisdom, and Pattern resources - reusable conceptual material for story direction

How It Fits the Product Flow

Library acts as a reusable source layer. It feeds planning surfaces but does not replace them.

Typical Uses

1. Build Faster

Select existing resources instead of creating every character, place, or structural pattern from zero.

2. Keep Consistency

Use shared templates to maintain a consistent style of arcs, characters, and world elements across projects.

3. Strengthen Planning

Apply Library resources while working in Story Core, Narrative Design, Blueprint, or Story Map.

4. Reverse Entry Into the Workflow

Library also works in reverse. Instead of entering a page first and opening a template there, authors can start in Library, click Apply, choose a valid target, and then continue editing in the destination page.

How to Use Library

  1. Open Library from the application header or from the Book Navigator.
  2. Select the resource family you want to browse.
  3. Review the template or reusable item.
  4. Click Apply.
  5. Select a valid target such as Book, a specific Chapter, or a Scene when available.
  6. Continue editing the selected item in the destination page if needed.

Target Rules

  • Narrative Arc Templates - usually apply to the whole book structure
  • Character Templates - apply to the book cast and can also support chapter-level planning
  • Locations - can apply to book, chapter, or scene depending on use
  • Objects & Artifacts - can apply to book, chapter, or scene
  • Narrative Blocks - best applied to chapters or scenes

Where Library Connects

  • Story Core - theme and high-level direction can be informed by reusable narrative material
  • Narrative Design - macro structure can align with reusable arc logic
  • Cast - character templates accelerate role definition
  • World - location and object resources can be added directly from Library
  • Blueprint - narrative arc templates support structural planning
  • Manuscript - chapter and scene targets can receive applicable resources from Library

Best Practices

  1. Use Library as a starting point, not as a final answer.
  2. Adapt templates to the specific story instead of applying them unchanged.
  3. Prefer a few strong reusable resources over many weak ones.
  4. Move back into Book Settings or Blueprint after applying a template so the project remains coherent.

NL Story

NL Story generates prose from the current CNL specification. This is the drafting stage where the planned story becomes readable narrative text.

When to Use This Page

Use NL Story after Book Settings, Blueprint, Story Map, and CNL review. You can also jump here through the Create Story shortcut in Story Core.

What This Page Does

  • Generates a first draft from the current CNL
  • Supports improve, regenerate, and stop actions from the same control surface
  • Manages draft versions for comparison and iteration
  • Passes the resulting content forward into Manuscript workflows

What Generation Uses

NL Story draws from the full project model, especially:

  • Story Core for theme, wisdom, and character transformation
  • Narrative Design for conflict logic and macro structure
  • Blueprint for beats, pacing, and tension
  • Story Map for chapter and scene arrangement
  • CNL Editor for the current specification source of truth

Typical Workflow

  1. Complete the minimum planning needed in Book Settings and Blueprint.
  2. Review the specification in CNL Editor.
  3. Open NL Story.
  4. Click Create Story to generate the first draft.
  5. Review the output and compare versions if needed.
  6. Use improve or regenerate when the current draft is not strong enough.
  7. Continue refining in Manuscript.

Quality Considerations

Specification State Expected Result
Minimal wizard only Fast but generic draft
Story Core + Narrative Design More coherent conflict and thematic direction
Full Book Settings + Blueprint + Story Map Stronger structural and character consistency

Metrics Relationship

The generated story can be evaluated against the project specification. If quality is weak, return to Story Core, Narrative Design, Blueprint, or Story Map before regenerating.

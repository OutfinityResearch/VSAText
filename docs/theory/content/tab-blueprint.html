Blueprint Tab

The Blueprint tab is the planning workspace for narrative structure and pacing. It unifies arc planning, beat mapping, emotional progression, and tension shaping in one flow.

When to Use This Tab

Use Blueprint early to choose your narrative arc, define the key event and primary conflict, inspect beat positions, shape pacing, and map beats to chapters/scenes.

What This Tab Does

  • Narrative Arc selection (7 work-level arc options)
  • Focus fields: Key Event and Primary Conflict
  • Visual Story Beats timeline with beat positions on 0% to 100%
  • Emotional Progression editor (beat to mood preset)
  • Tension Curve editor with Add Point and Reset
  • Beat Mapping from beats to chapters/scenes with optional tension inputs
  • Subplots planning for secondary narrative threads

Blueprint Structure (Logical Order)

  1. Title + Introduction - Architectural context for planning
  2. Narrative Arc - Select structure template
  3. Key Event + Primary Conflict - Define core dramatic anchor
  4. Visual Beats Timeline - Review beat progression and positions
  5. Emotional Progression - Assign mood presets by beat
  6. Tension Curve - Shape macro pacing and intensity
  7. Beat Mapping - Connect beats to concrete chapters/scenes
  8. Subplots - Plan secondary narrative threads

Core Components

1. Narrative Arc + Focus Fields

Select the arc and lock narrative intent with Key Event and Primary Conflict.

2. Story Beats Timeline

Each yellow marker represents a beat position on story progress (0% to 100%). Beat labels and percentages help orientation before mapping.

3. Emotional Progression

Assign mood presets per beat to define macro emotional flow. This complements scene-level moods and supports EAP alignment.

4. Tension Curve

Use interactive points to shape intensity from 0% to 100%. Keep Add Point and Reset available for rapid iteration.

5. Beat Mapping

Bind each beat to chapter/scene targets and set explicit tension values when needed.

6. Subplots

Define subplot type, characters, start and resolve beats, and key touchpoints.

// Arc selection

// Tension curve
Tension at 0.0 is 1

// Subplots
Subplot S1 type romance
S1 starts at beat crossing_threshold
S1 resolves at beat return_elixir

Metrics Impact

  • Beat Coverage: whether selected arc beats are represented
  • EAP: beat mood progression and pacing consistency
  • Pacing Score: tension distribution quality
  • Subplot Integration: depth and coherence of secondary threads

Best Practices

  1. Select the narrative arc before mapping chapters.
  2. Lock key beats first (inciting event, midpoint, climax, resolution).
  3. Use Emotional Progression to avoid flat tone.
  4. Shape the tension curve before detailed scene writing.
  5. Keep subplots synchronized with main-arc turns.

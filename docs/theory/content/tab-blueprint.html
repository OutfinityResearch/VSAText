Blueprint Tab

The Blueprint tab is the primary planning workspace for narrative structure and pacing. It defines how the story will unfold before that structure is formalized in CNL and used by NL Story.

When to Use This Tab

Use Blueprint immediately after project creation and before reviewing CNL. This is where you choose the narrative arc, shape pacing, map beats to scenes, and establish the structural plan that the rest of the workflow depends on.

What This Tab Does

  • Narrative Arc selection (7 supported arc options)
  • Focus fields: Key Event and Primary Conflict
  • Visual Story Beats timeline with beat positions on 0% to 100%
  • Emotional Progression editor (beat to mood preset)
  • Tension Curve editor with Add Point and Reset
  • Beat Mapping from beats to chapters/scenes with tension values
  • Subplots planning for secondary narrative threads
  • Automatic synchronization of arc-dependent data when the arc changes

Workflow Position

New Project

In the current product flow, Blueprint comes before CNL. Users first define the structural story plan here, then inspect that plan in formal CNL form, and only after that continue to prose generation.

Blueprint Structure (Logical Order)

  1. Title + Introduction - Architectural context for planning
  2. Narrative Arc - Select structure template
  3. Key Event + Primary Conflict - Define core dramatic anchor
  4. Visual Beats Timeline - Review beat progression and positions
  5. Emotional Progression - Assign mood presets by beat
  6. Tension Curve - Shape macro pacing and intensity
  7. Beat Mapping - Connect beats to concrete chapters/scenes
  8. Subplots - Plan secondary narrative threads

Core Components

1. Narrative Arc + Focus Fields

Select the arc and lock narrative intent with Key Event and Primary Conflict.

2. Story Beats Timeline

Each yellow marker represents a beat position on story progress (0% to 100%). Beat labels and percentages help orientation before mapping.

3. Emotional Progression

Assign mood presets per beat to define macro emotional flow. This complements scene-level moods and supports EAP alignment.

4. Tension Curve

Use interactive points to shape intensity from 0% to 100%. Keep Add Point and Reset available for rapid iteration.

5. Beat Mapping

Bind each beat to chapter/scene targets and set explicit tension values when needed.

6. Subplots

Define subplot type, characters, start and resolve beats, and key touchpoints.

Arc Synchronization

Changing the narrative arc is a structural decision, not a cosmetic label change. When you switch the arc, SCRIPTA rebuilds the arc-dependent planning layer so the project remains internally coherent.

  • Beat mappings are rebuilt for the selected arc.
  • Tension curve is refreshed to match the new beat progression.
  • Scene and chapter titles are updated when they are still auto-generated.
  • Dialogues and hooks are synchronized so their beat references continue to point to valid story beats.

This is why Blueprint should be considered the authoritative structural layer of the story. CNL exposes the result, but Blueprint is where the structure is decided.

CNL Output

// Arc selection
Blueprint uses arc heros_journey

// Blueprint focus
Blueprint has key_event "Treaty is broken at coronation"
Blueprint has primary_conflict "Protagonist vs system"

// Beat mappings
Beat call_to_adventure mapped to Ch2.Sc1
call_to_adventure has tension 3

// Emotional progression
call_to_adventure has mood mysterious

// Tension curve
Tension at 0.0 is 1
Tension at 0.5 is 4
Tension at 0.9 is 5

// Subplots
Subplot S1 type romance
S1 starts at beat crossing_threshold
S1 resolves at beat return_elixir

Metrics Impact

  • Beat Coverage: whether selected arc beats are represented
  • EAP: beat mood progression and pacing consistency
  • Pacing Score: tension distribution quality
  • Subplot Integration: depth and coherence of secondary threads
  • CNL Consistency: Blueprint changes propagate into the formal specification used for validation and generation

Best Practices

  1. Select the narrative arc before mapping chapters and scenes in detail.
  2. Lock key beats first (inciting event, midpoint, climax, resolution).
  3. Use Emotional Progression to avoid flat tone.
  4. Shape the tension curve before detailed scene writing.
  5. After major Blueprint changes, review the CNL page to confirm the formal structure is still what you want.
  6. Keep subplots synchronized with main-arc turns.

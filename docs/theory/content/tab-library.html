Library

Library is the reusable resource area of the application. It stores narrative assets that can be selected and reused across projects instead of being rebuilt from scratch each time.

Workflow Position

Library supports the main writing flow, but it is not a mandatory linear step. Authors typically create a project first, then pull reusable material from Library while working through Book Settings, Blueprint, or Story Map.

What Library Contains

  • Narrative Arc Templates - reusable arc models and structural patterns
  • Character Templates - reusable character seeds, archetypes, and trait bundles
  • Locations - reusable settings and place definitions
  • Objects & Artifacts - reusable story objects and symbolic items
  • Scenes & Plot Points - reusable structural or dramatic building blocks

Library acts as a reusable source layer. It feeds planning surfaces but does not replace them.

Typical Uses

1. Build Faster

Select existing resources instead of creating every character, place, or structural pattern from zero.

2. Keep Consistency

Use shared templates to maintain a consistent style of arcs, characters, and world elements across projects.

3. Strengthen Planning

Apply Library resources while working in Story Core, Narrative Design, Blueprint, or Story Map.

How to Use Library

  1. Open Library from the application header or from the Book Navigator.
  2. Select the resource family you want to browse.
  3. Review the template or reusable item.
  4. Apply it to the current project where relevant.
  5. Continue editing the selected item in the destination page if needed.

Where Library Connects

  • Story Core - theme and high-level direction can be informed by reusable narrative material
  • Narrative Design - macro structure can align with reusable arc logic
  • Cast - character templates accelerate role definition
  • World - location resources provide reusable setting logic
  • Blueprint - narrative arc templates support structural planning

Best Practices

  1. Use Library as a starting point, not as a final answer.
  2. Adapt templates to the specific story instead of applying them unchanged.
  3. Prefer a few strong reusable resources over many weak ones.
  4. Move back into Book Settings or Blueprint after applying a template so the project remains coherent.

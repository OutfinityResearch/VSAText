Story Core

Story Core is the first editorial planning page inside Book Settings. It defines the foundation of the book before Blueprint, Story Map, CNL editing, and prose generation.

Workflow Position

After project creation, the application opens Book Settings and starts with Story Core. Authors can continue through the full workflow or use Create Story as a shortcut to NL Story.

What This Tab Includes

  • Story Fundamentals: complexity, number of characters, world rules summary, and wisdom
  • Theme: thematic templates with reusable descriptions and auto-fill behavior
  • Character Transformation: before/after arc, value shift, and cost of change
  • Create Story: shortcut action that triggers the same generation flow used in NL Story

Layout and UX

  • Large labels, generous spacing, and premium card styling for comfortable reading
  • Theme cards are compact and selection-focused rather than overloaded with metadata
  • Character transformation fields are stacked vertically for faster scanning
  • Header keeps the page title visible and exposes the Create Story shortcut
  • Visual language matches Narrative Design for consistency across Book Settings

Section Behavior

Story Fundamentals

Use this section to define the book at a high level. Keep the inputs concise and directional. These values influence the rest of planning and the generated CNL.

Theme

Select a theme template to pull in its narrative meaning. Theme selection can auto-fill the linked project theme, wisdom, moral question, transformation axis, and ideological conflict values used elsewhere in the project. Theme cards in Story Core stay compact and editorial rather than overloaded with metadata.

Character Transformation

This section captures the protagonist change in three compact cards:

  • Character Arc: Before and After
  • Value Shift: Believed and Learns
  • Cost of Change: what the hero must lose

What Story Core No Longer Holds

Story Core no longer duplicates structural planning that belongs elsewhere in the flow.

  • Structural Arc and Turning Points are handled in Blueprint and Narrative Design
  • Dramatic Model was reduced so Story Core stays focused on editorial direction
  • Themes are selected here, but the old separate Themes step is no longer part of the main left-side flow

CNL Relationship

Story Core feeds directly into the same project model used by CNL generation:

  • Theme and wisdom values contribute to the thematic sections of the generated specification
  • Character transformation enriches arc interpretation and draft generation prompts
  • Story fundamentals provide high-level guidance for Blueprint, Story Map, and NL generation

Best Practices

  1. Keep Story Fundamentals directional, not exhaustive.
  2. Select one strong theme before adding structural detail in Blueprint.
  3. Write Character Transformation in plain, contrast-rich terms.
  4. Use Create Story only when the current setup is strong enough for drafting.
  5. Continue to Narrative Design when you need clearer conflict and macro structure.

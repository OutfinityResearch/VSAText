Framework Tab

The Framework tab unifies the former Themes, World Rules, and Moods planning workflows into a single narrative design surface.

What Changed

Framework is now the central place for thematic strategy, world constraints, and emotional control. The old tabs remain as legacy references but the active workflow is unified here.

What This Tab Includes

  • Themes: thematic cards with suggested narrative blocks
  • World: world-rule cards with category, rule title, and compact description
  • Mood Engine: focused emotional planning with Global Tone, Scene Mood cards, and Mood Preview

Layout and UX

  • Distinct section colors for fast visual parsing
  • Consistent card sizing and styling for premium coherence
  • Dedicated add cards: Add Theme, Add World, Add Mood
  • Every data card is clickable for edit/detail workflows
  • Responsive grid optimized for landscape planning sessions

Section Behavior

Themes

Theme cards expose title and suggested blocks. Use them to align structural decisions with narrative meaning.

World

World cards capture hard constraints that generation should respect (society, technology, magic, geography, etc.).

Mood Engine

The current Mood Engine includes three blocks:

  • Global Tone: dropdown with multiple tonal presets and tags
  • Scene Mood: mood cards with emotions, intensity, and add/edit actions
  • Mood Preview: visual preview panel for expected emotional flow

CNL Relationship

Framework edits feed directly into the same project model used by CNL generation:

  • Themes -> // Themes section
  • World Rules -> // === WORLD RULES === section
  • Moods / Emotional planning -> mood-related blueprint and scene references

Best Practices

  1. Start by defining 1-2 primary themes.
  2. Add world constraints that materially affect decisions.
  3. Pick one clear Global Tone before editing individual scene moods.
  4. Use Mood Preview to validate tonal consistency.
  5. Keep card content concise and operational.

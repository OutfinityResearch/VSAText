World

The World page unifies Locations, Objects & Artifacts, World Rules, and World Layers into one literary workspace for story settings. In this context, settings means the narrative environment (place, time, relevant objects, and governing rules), not technical app preferences.

Literary Meaning of Settings

Use World to define where action happens, when it happens, what objects materially influence scenes, and what rules govern the setting.

What World Includes

  • Locations: places where scenes occur (city, kingdom, planet, ruins)
  • Time Period: era or temporal framing attached to locations
  • Objects: story-relevant items (keys, artifacts, documents, weapons)
  • World Rules: social, magical, technological, or physical constraints
  • World Layers: societies, histories, systems, and contextual logic

Why This Merge Helps

  • Keeps all setting context in one place
  • Makes scene planning faster and more coherent
  • Improves consistency between location logic and object usage
  • Lets authors pull reusable location and object seeds directly from Library

Recommended Workflow

  1. Add 3-6 core locations with clear geography and time period.
  2. Add 2-5 meaningful objects that affect conflict, clues, or turning points.
  3. Use Add from Library when you want to start from reusable location or object templates.
  4. Reference those locations and objects in scenes from the structure tree.
  5. Reuse key backdrops across chapters to strengthen narrative continuity.

CNL Impact

World entries are serialized as standard location, object, and world-rule entities in CNL. Existing CNL format and generation behavior remain unchanged.

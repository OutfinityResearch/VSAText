Backdrop Tab

The Backdrop tab unifies Locations and Objects into one literary workspace for story settings. In this context, settings means the narrative environment (place, time, and relevant objects), not technical app preferences.

Literary Meaning of Settings

Use Backdrop to define where action happens, when it happens, and what objects materially influence scenes.

What Backdrop Includes

  • Locations: places where scenes occur (city, kingdom, planet, ruins)
  • Time Period: era or temporal framing attached to locations
  • Objects: story-relevant items (keys, artifacts, documents, weapons)

Why This Merge Helps

  • Keeps all setting context in one place
  • Makes scene planning faster and more coherent
  • Improves consistency between location logic and object usage

Recommended Workflow

  1. Add 3-6 core locations with clear geography and time period.
  2. Add 2-5 meaningful objects that affect conflict, clues, or turning points.
  3. Reference those locations and objects in scenes from the structure tree.
  4. Reuse key backdrops across chapters to strengthen narrative continuity.

CNL Impact

Backdrop entries are serialized as standard location and object entities in CNL. Existing CNL format and generation behavior remain unchanged.

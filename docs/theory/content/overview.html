SCRIPTA Research Studio

SCRIPTA is a story planning and generation studio built around a specification-first workflow. The application helps authors move from project intent to narrative design, formal story specification, prose generation, and manuscript refinement.

Core Product Idea

SCRIPTA does not begin with a one-shot prompt. It begins with a project, shapes the story foundation in Book Settings, formalizes that foundation in CNL, and then generates prose from the resulting specification.

Natural Workflow

Create Project
      ↓
Book Settings
      ↓
Blueprint
      ↓
Story Map
      ↓
CNL Editor
      ↓
NL Story
      ↓
Manuscript

This is the recommended flow for new work. Iteration can happen at any stage, but the strongest results usually come from moving through the sequence in order.

What Each Step Does

New Project

Create the project with title, format, length, and seed ideas. After clicking Create Project, the app opens Book Settings.

Story Core

Define story fundamentals, theme, wisdom, and character transformation. This is the editorial foundation of the book.

Narrative Design

Define core conflict, macro structure, escalation, and storytelling constraints before structural planning.

Blueprint

Shape arc, beats, key events, pacing, and tension. Blueprint is the main structural planning surface.

Story Map

Map chapters and scenes across the book and connect macro structure to concrete flow.

CNL Editor

Inspect and edit the formal specification that powers analysis, generation, and export.

NL Story

Generate the story draft, improve it, regenerate it, and manage versions from the current specification.

Manuscript

Continue drafting and editing chapter and scene content in manuscript form after generation.

Book Settings

Book Settings is the first major planning stage after project creation. It includes:

  • Story Core - story fundamentals, theme, wisdom, and character transformation
  • Narrative Design - core conflict, macro structure, escalation, and constraints
  • Cast - reusable or project-specific characters
  • World - settings, locations, and world logic
  • Themes - reusable thematic templates
  • Tone & Style - language direction for generation

In practice, Story Core and Narrative Design define the strongest part of the foundation before Blueprint begins.

Shortcut Workflow

SCRIPTA also supports a faster path for users who do not want to complete every planning step first.

  • Use Create Story in Story Core to jump directly into the NL Story generation flow
  • This shortcut uses the same generation logic as the main Create Story action in NL Story
  • The shortcut is useful for rapid drafting, but more complete planning usually produces stronger output

Why CNL Matters

CNL is the formal specification layer between planning and prose. It turns visual decisions into a consistent textual representation that the SDK can parse, evaluate, and send into generation.

// Character definition
Anna is hero
Anna has trait courage

// Relationship
Anna relates to Gandalf as mentor_student

// World rule
World is setting
R1 is world_rule
R1 has text "Magic requires sacrifice"
World includes rule R1

How to Start

  1. Click New in the application header.
  2. Complete the New Project wizard.
  3. Continue in Story Core.
  4. Refine the conflict in Narrative Design.
  5. Build structure in Blueprint and Story Map.
  6. Review the specification in CNL Editor.
  7. Generate the draft in NL Story.
  8. Continue editing in Manuscript and evaluate quality as needed.

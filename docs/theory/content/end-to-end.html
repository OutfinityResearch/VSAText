End-to-End Example

This document walks through the current SCRIPTA workflow from New Project to Manuscript, including the planning path, the formal CNL specification, prose generation, and metric-guided iteration.

Example Story: "The Silver Key"

We'll create a short fantasy story about a young woman who discovers a magical key that unlocks a hidden power. This compact example demonstrates all major SCRIPTA features.

Current Workflow

Recommended path: New Project -> Book Settings -> Story Core -> Narrative Design -> Blueprint -> Story Map -> CNL Editor -> NL Story -> Manuscript

Shortcut: New Project -> Story Core -> Create Story -> NL Story

Phase 1: New Project and Book Foundation

Step 1.0: Start in New Project

We begin in New Project, where the author creates the project and enters the foundation: title, length, high-level genre direction, and a few seed ideas.

  • Title: The Silver Key
  • Length: Short book
  • Genre direction: Fantasy adventure
  • Seed ideas: magical key, hidden inheritance, corrupt rival, costly power

After the wizard, the recommended path continues into Book Settings.

Phase 2: Book Settings and Libraries

Step 2.1: Create Characters

First, we define the cast in the Cast page:

Name Type Archetype Traits
Elena protagonist Hero curious, determined, compassionate
Mira mentor Sage wise, mysterious, patient
Valdris antagonist Shadow ambitious, cunning, ruthless
Finn character Ally loyal, humorous, brave

Step 2.2: Define Relationships

In the Cast page, we establish relationships and dynamics:

  • Elena relates to Mira as mentor_student, dynamic protective
  • Elena relates to Finn as friend, dynamic supportive
  • Valdris relates to Elena as enemy, dynamic manipulative
  • Mira relates to Valdris as former_ally, dynamic toxic

Step 2.3: Build World Locations

In the World page, we define the core settings:

Name Geography Atmosphere Characteristics
Millbrook Village rural peaceful "cobblestone streets", "ancient clock tower"
Whispering Woods forest mysterious "silver-barked trees", "enchanted paths"
The Hidden Vault underground threatening "crystal formations", "ancient runes"

Step 2.4: Add World Objects

Still in World, we add story-relevant objects:

Object Type Significance Description
Silver Key artifact high Ancient key that unlocks dormant magical abilities
Mira's Journal document medium Contains clues about the key's true power

Step 2.5: Define Story Core Direction

In Story Core, we define the book's editorial direction:

  • Complexity: layered but readable
  • World Rules: magic is inherited but must be unlocked
  • Wisdom: power without restraint becomes self-destruction

Step 2.6: Select Theme and Character Transformation

Still in Story Core, we define the protagonist change and thematic frame:

  • Theme: Power
  • Ideological Conflict: control promises safety, but corrupts what it claims to protect
  • Character Arc: curious villager → responsible guardian
  • Value Shift: power solves everything → power can destroy what you love

Step 2.7: Set Narrative Design

In Narrative Design, we lock the conflict and macro plan before detailed mapping:

  • Central Conflict: Elena must master the Silver Key before Valdris claims it
  • Resolution Path: Sacrifice
  • Structure Model: Story Circle
  • Escalation Pattern: Spiral

At this point, the author could already use Create Story in Story Core to jump directly to NL Story and generate a quick draft. In this example we continue through the full planning path.

Phase 3: Blueprint and Story Map

Step 3.1: Select Narrative Arc

We choose the Story Circle (Dan Harmon) arc with 8 beats, appropriate for a compact story:

  1. You (Comfort Zone) - Elena in her ordinary life
  2. Need (Want Something) - Elena discovers she might have magic
  3. Go (Enter Unfamiliar) - Journey into Whispering Woods
  4. Search (Adapt) - Learning from Mira, facing challenges
  5. Find (Get It) - Discovers the Silver Key
  6. Take (Pay Price) - Confrontation with Valdris, sacrifice
  7. Return - Back to village with new abilities
  8. Change - Elena transformed, new responsibilities

Phase 5: Generate Prose in NL Story

In NL Story, the author clicks Create Story. The system uses the project foundation and CNL specification to generate a narrative draft.

Generated Excerpt (Scene 3)

"The silver-barked trees of the Whispering Woods seemed to watch Elena as she stepped deeper into the forest. She had followed the strange pull in her chest since dawn, and now, as twilight painted the sky in shades of violet, she found herself face to face with an old woman whose eyes held the weight of centuries.

'You are not ordinary, Elena,' the woman said, her voice like wind through ancient leaves. 'You never were. Your mother... she was one of us. And the power that sleeps within you - it's time to wake it.'"

Phase 8: Manuscript and Final Export

After the first NL draft and evaluation pass, the author moves into Manuscript to continue chapter and scene refinement, then exports the assets needed for later work.

Export Options

  • Export CNL: Download the specification as the-silver-key.cnl
  • Export Project: Save complete project JSON for later editing
  • Export NL: Download the generated NL Story draft
  • Save to Server: Persist for team collaboration

Key Takeaways

  1. Project foundation comes first: Start in New Project, then deepen the story through Book Settings, Story Core, and Narrative Design
  2. Structure follows intent: Use Blueprint and Story Map only after the conflict, world, and cast are clear
  3. CNL is the formal bridge: The CNL Editor exposes the specification that powers validation, export, and NL Story generation
  4. Metrics guide improvement: Coverage, Coherence, and NQS help identify where the draft needs refinement
  5. Manuscript is the editorial layer: After NL Story generation, continue refining chapters and scenes in Manuscript
  6. Relationships and dialogue must manifest in scenes: planning alone is not enough; the draft has to show those elements on the page
